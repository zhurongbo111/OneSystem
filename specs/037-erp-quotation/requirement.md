# 需求规格：报价单（erp-quotation）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P3 主数据与政策**第三项；销售订单（`024`）**前段**，CRM 轻量入口。
> 依赖：`012`（商品）、`013`（客户）、`024`（销售订单 —— 转单目标）、`036`（客户协议价 —— 取价）。
> 本规格**不锁定库存、不产生资金**（报价是意向，非业务发生）。

## 1. 背景

现状销售链路从**销售订单**（`024`）开始，**缺失其前段「报价」**：

- 给客户的报价（含有效期）无处记录，只能线下 Excel，转订单时重新录一遍。
- `036-erp-partner-price`（已起草）提供客户协议价，报价单是它最自然的第一消费场景。

本规格补齐"报价单 → 销售订单"这一小段：报价可留档、可带出协议价、可一键转单。

## 2. 目标

1. **报价单**：客户、报价日期、有效期、明细（商品 / 数量 / 单价）+ 备注；单号前缀 **`QT`**（`ROADMAP` §6.7 续行）。
2. **状态**：`草稿`（可编辑 / 可作废）/ `已转订单`（锁定）/ `已作废`；有效期已过在展示上标「已过期」。
3. **取价**：明细单价默认取 `036` 客户协议价（无则商品销售价），可手工改。
4. **转销售订单**：一次性把报价单转为销售订单（`024`），回写转换关系并锁定报价单为「已转订单」。
5. **不产生库存 / 资金影响**：报价单不锁库存、不写流水、不产生应收。
6. **权限与菜单**：权限点续行至 `028` §0.2（`quotations.*`）；菜单续行至 `025` §0.2「销售」分组。
7. **前端**：报价单列表 / 表单页 / 详情；明细支持按客户批量取价。
8. **e2e 覆盖**。

## 3. 功能点

- **F1 报价单列表**：`GET /api/quotations`（按单号 / 客户关键词、状态、日期范围筛选 + 分页）。
- **F2 报价单详情**：`GET /api/quotations/{id}`（含明细与转换信息）。
- **F3 新建 / 编辑**：`POST /api/quotations`、`PUT /api/quotations/{id}`（**仅草稿可编辑**，否则 `40166`）；明细数量 / 单价边界沿用商品约束；金额后端重算。
- **F4 作废**：`PUT /api/quotations/{id}/void`（仅草稿；已转订单 → `40166`）。
- **F5 转销售订单**：`POST /api/quotations/{id}/convert` → 生成销售订单（`024` 的 `SalesOrders`），复制明细，回写 `ConvertedOrderId` / `ConvertedOrderNo`，状态置「已转订单」；已转 / 已作废 → `40167`。
- **F6 取价**：明细按客户批量取 `036` 生效价（一次请求），标注价格来源。
- **F7 权限与菜单**：§0 续行 `028` / `025`（销售分组）。
- **F8 e2e**：建报价单（带出协议价）→ 编辑 → 转销售订单 → 报价单锁定、订单出现；已转单再作废 / 再转 → `40166` / `40167`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（状态流转、编辑 / 作废 / 转单限制、取价、金额重算等单测）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `quotation.spec.ts`）。
3. 手工验证：
   - 客户 A 配置协议价 8.80 → 新建报价单选客户 A、商品 → 单价 8.80 且标注「协议价」；改客户为无协议价者 → 回退销售价。
   - 草稿可编辑；转销售订单后报价单「已转订单」、订单列表出现该 `SO` 单；再作废 / 再转 → `40166` / `40167`。
   - 报价单不改变库存与应收（对账前后一致）。
4. 口径单一：报价单状态取值与文案、转单规则、取价优先级只在 `design.md` §0 定义一次（取价复用 `036` §0，不重复定义）。
5. 联动：`024` `design.md` 加「演进（erp-quotation）」注记（订单可来自报价转单）；`ROADMAP` §6.7 续行 `QT`；`028` §0.2 / `025` §0.2 续行。

## 5. 范围外（不做）

- **报价单审批 / 发送 / 邮件 / 短信**：不做对外发送。
- **报价版本 / 修订历史**：单值（改了即覆盖），变更留痕走 `029`。
- **报价转其他单据**（采购 / 直接出库）：只转销售订单。
- **报价单导出 / 打印**：一期不做（如需复用 `027` 另评）。
- **报价与订单的双向同步**：订单修改不回流报价。
- **阶梯价 / 促销 / 折扣率**：`036` 范围外的延续；报价单只带单一单价。
- **报价的有效期过期自动作废**：仅展示「已过期」标签，不自动改状态。
- **报价单部分转单**（只转部分明细）：一次性整单转。
