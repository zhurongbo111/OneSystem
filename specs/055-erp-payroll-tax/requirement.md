# 需求规格：个税与社保（erp-payroll-tax）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P8 深化**项（**待评估**：须业务场景确认后启用）；补齐 `ROADMAP` §3「人力域 · HCM 考勤 / 薪酬」的「个税 / 社保」后置缺口。
> 依赖：`044`（工资单 / 实发公式 / 发放锁定）、`030`（员工）、`028`（权限）。
> 范围克制：只做**工资单税务字段扩展 + 个税自动计算（累计预扣预缴法）+ 社保个人部分录入**；不做社保方案 / 缴费基数字典、单位部分、税务申报、薪酬凭证。

## 1. 背景

`044` 的工资单是「基本工资 + 津贴 − 扣款 = 实发」，**没有个税与社保**：

- 个税是工资发放的刚性项，手工算易错（累计预扣法要跨月累计），且"实发"不准。
- 社保个人部分（养老 / 医疗 / 失业等）是税前扣除项，直接决定应纳税所得额。
- 个税采用**累计预扣预缴法**（居民个人工资薪金），需按员工本年度 1..M 月累计收入 / 扣除 / 已缴税推算本期税额——纯手工不可行。

本规格补上：工资单增社保 / 专项附加扣除 / 个税字段，个税按累计预扣法自动计算，实发公式随之调整。

## 2. 目标

1. **字段扩展**：工资单增 `SocialInsurance`（个人社保）、`SpecialDeduction`（专项附加扣除）、`Tax`（个税，系统计算）；`Deduction` 明确为**税后其它扣款**。
2. **实发公式**（修订 `044` §0.1）：`NetPay = BaseSalary + Allowance − SocialInsurance − Tax − Deduction`。
3. **个税自动计算**：按累计预扣预缴法（7 级预扣率表 + 每月减除 5000）计算本期 `Tax`；单条计算 + 批量生成时自动带出。
4. **累计口径**：累计收入 / 社保 / 专项附加 / 已缴税取该员工**本年度已存在**的工资单（缺月按 0）。
5. **不新增权限点 / 菜单**：复用 `payroll.*`（`028` §0.2），页面仍在「人事 → 薪酬」。
6. **前端**：工资单表单增三字段 + 个税计算；**e2e 覆盖**。

## 3. 功能点

- **F1 字段扩展**：`Payrolls` 增 `SocialInsurance` / `SpecialDeduction` / `Tax`；实发公式更新（`044` §0.1 修订）。
- **F2 个税计算**：`PayrollTaxCalculator`（`App.Core/Features/Payrolls/`，纯函数，可单测）——累计预扣预缴法；`POST /api/payrolls/{id}/calculate-tax`。
- **F3 批量生成带税**：改造 `Payrolls/GeneratePayrolls`：生成时按累计法自动算 `Tax`（社保 / 专项附加取默认 0，人工可调）。
- **F4 发放锁定**：已发放（`Paid`）工资单禁改 / 禁重算（复用 `044` 的 `40171`）。
- **F5 e2e**：生成工资单 → 个税按累计法计算 → 实发 = 应发 − 社保 − 个税 − 其它扣款；次月生成时累计生效。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（税率表边界、累计法跨月、实发公式、锁定复用）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `payroll-tax.spec.ts`）。
3. 手工验证：
   - 员工月收入 10,000、社保 1,000、专项附加 1,000 → 1 月个税 = (10000 − 5000 − 1000 − 1000) × 3% = 90；实发 = 10000 − 1000 − 90 − 0。
   - 2 月同参数 → 累计应纳税所得额 6,000 → 累计税额 180 − 已缴 90 = 90。
   - 已发放工资单重算个税 → `40171`。
4. 口径单一：实发公式、个税公式、税率表、扣除项范围只在 `design.md` §0 定义一次。
5. 联动：`044` §0.1（实发公式）/ §2.2（工资单字段）/ §3.3（新端点）改写为最终态 + 演进指针；`028` §0.2 **无新增权限点**；`ROADMAP` §6 错误码**无新增**。

## 5. 范围外（不做）

- **社保方案 / 缴费基数 / 费率字典 / 参保地差异**：本期社保个人部分**人工录入**（可在批量生成后逐条调整）。
- **社保单位部分 / 公积金 / 企业年金**：不做。
- **个税年度汇算清缴 / 补退税 / 申报表导出**：只做月度预扣预缴。
- **非居民 / 劳务报酬 / 年终奖单独计税**：只做居民工资薪金累计预扣。
- **薪酬与总账联动（计提工资 / 代扣个税 / 社保凭证）**：不做（如需另评）。
- **工资单导出 / 工资条 / 银行代发文件**：一期不做。
- **多币种薪酬 / 异地社保**：不做。
