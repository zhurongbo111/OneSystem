# 需求规格：固定资产（erp-fixed-asset）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P8 深化**项（**待评估**：须业务场景确认后启用）；`ROADMAP` §7 原「预算 / 固定资产 / 费用报销」范围外项之一，本轮改列待评估。
> 依赖：`033`（凭证 / 期间闸门 / 自动凭证通道 / 科目映射）、`031`（科目 / 预置科目）、`028`（权限）。
> 范围克制：只做**资产台账 + 直线法月度折旧 + 折旧凭证 + 简化处置**；不做取得凭证、处置损益、减值、变更、卡片打印、条形码。

## 1. 背景

`033` 总账体系已覆盖业务单据，但**固定资产**（设备 / 车辆 / 办公资产）没有台账与折旧：

- 资产原值、累计折旧、净值无处记录，资产负债表缺「固定资产 / 累计折旧」科目余额来源。
- 折旧是每月固定动作，靠手工做凭证易漏、口径不一（残值 / 使用年限因人而异）。
- `031` 已有科目树与预置科目机制、`033` 已有凭证写入通道——固定资产只差台账与月度计提能力。

本规格补上**固定资产**：台账登记 → 按月直线法计提折旧（自动凭证）→ 简化处置。

## 2. 目标

1. **资产台账**：登记编码 / 名称 / 取得日期 / 原值 / 预计使用月数 / 残值 / 折旧费用科目；状态（在用 / 已处置）。
2. **月度折旧**：直线法（年限平均）批量计提，生成折旧凭证（借 折旧费用科目 / 贷 累计折旧），更新累计折旧与已提月数。
3. **幂等**：同一期间不重复计提；已提完 / 已处置资产不参与。
4. **简化处置**：标记「已处置」并停止折旧（**不生成处置损益凭证**，见范围外）。
5. **权限与菜单**：权限点续行 `028` §0.2（`fixedAssets.*`）；菜单「财务」分组续行（`025` §0.2）。
6. **前端**：资产列表 / 表单 / 计提折旧 + 处置；**e2e 覆盖**。

## 3. 功能点

- **F1 资产台账**：`GET /api/fixed-assets`（关键词 / 状态 / 期间筛选 + 分页）、`POST`、`PUT /{id}`、`GET /{id}`；编码 `FA + yyyyMMdd + 4`。
- **F2 月度折旧计提**：`POST /api/fixed-assets/depreciate`（入参期间 `YYYY-MM`）；同期间重复 → `40188`；无资产可提 → `40189`。
- **F3 处置**：`PUT /{id}/dispose`（已处置 / 已提完另议 → `40190`）；处置后不再计提。
- **F4 科目续行**：`033` §0.3 映射键续行 `FixedAsset` / `AccumDepreciation` / `DepreciationExpense`；`031` §2.4 预置科目（如缺）续行 `1601 固定资产` / `1602 累计折旧` / `6602 管理费用`。
- **F5 权限与菜单**：`028` §0.2 续行 `fixedAssets.*`；`025` §0.2「财务」分组续行。
- **F6 e2e**：建资产 → 计提 → 累计折旧与凭证正确；重复计提 `40188`；处置后不再计提。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（折旧计算边界、幂等、处置限制、凭证模板）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `fixed-asset.spec.ts`）。
3. 手工验证：
   - 建资产（原值 12,000、使用 24 月、残值 0）→ 计提当月 → 月折旧 500、凭证「借 折旧费用 500 / 贷 累计折旧 500」、累计折旧 500、净值 11,500。
   - 同月再计提 → `40188`；末月折旧取差额不超原值 − 残值。
   - 已处置资产不再参与计提。
4. 口径单一：折旧公式 / 计提判据 / 凭证模板只在 `design.md` §0 定义一次。
5. 联动：`033` §0.1 / §0.3 续行、`031` §2.4 续行、`028` §0.2 续行、`025` §0.2「财务」分组续行、`ROADMAP` §6 错误码续行、§7 条目改列待评估。

## 5. 范围外（不做）

- **取得（购置）自动凭证**：本期台账登记不生成购入凭证（走 `015` 采购或人工凭证）；如需另评。
- **处置损益凭证 / 清理科目**：处置只标记状态，不做账面清理分录。
- **减值准备 / 折旧方法变更 / 会计估计变更**：只做直线法。
- **工作量法 / 双倍余额递减法 / 年数总和法**：不做。
- **资产变更（调拨 / 部门 / 使用人 / 位置）**：本期无部门 / 使用人维度。
- **资产盘点 / 卡片打印 / 条码**：不做。
- **在建工程 / 无形资产 / 长期待摊**：不做。
- **预算联动 / 资产预算**：见 `054-erp-budget`（待评估），不联动。
