# 需求规格：经营分析看板（erp-dashboard）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P7 内核收口与运营**项；补齐 L5 分析层（`ROADMAP` §3「L5 分析 · 报表」缺口为「经营分析看板」）。
> 依赖：`025`（进销存 / 采购 / 销售汇总口径）、`026`（成本毛利）、`023`（应收应付未结）、`034`（资金余额）、`033`（损益）、`041` / `042`（预警 / 审批待办）、`036` / `047`（逾期应收）。
> 范围克制：**只读聚合**，不新增任何写入路径；不引入 BI（自定义维度 / 拖拽 / 下钻建模）。

## 1. 背景

`025` / `033` 已提供明细报表（进销存、库存余额、采购 / 销售汇总、成本毛利、三大报表），但它们**面向具体业务明细**，管理者"一屏看经营"缺一个总览：

- 销售额 / 采购额 / 毛利 / 库存 / 应收应付 / 资金 / 逾期 / 待办散落在多个页面，需逐一打开并各自筛时间。
- 缺少趋势（近 12 月销售 / 采购走势）与 TOP（畅销商品 / 大客户）这类"经营视角"聚合。
- 上述口径**均已存在**（`025` / `026` / `023` / `034`），只差一个聚合入口——本规格不新造口径，只做**只读汇集**。

本规格补上 L5 的**经营分析看板**：KPI 卡片 + 趋势图 + TOP 榜，一个时间区间内总览经营全貌。

## 2. 目标

1. **KPI 总览**：区间内销售净额 / 采购净额 / 毛利（额 + 率）；时点值库存数量 / 金额、应收未结、应付未结、逾期应收、资金余额、待审批数、库存预警数。
2. **趋势**：近 12 个月销售 / 采购净额月度趋势。
3. **TOP 榜**：区间内销售 TOP 商品、TOP 客户（金额降序，取前 10）。
4. **口径复用**：全部指标沿用既有规格口径（`design.md` §0.1 只登记"指标 → 来源口径"指针，不重新定义算法）。
5. **前端**：单页看板（区间选择 + 卡片 + 图 + 榜）；**e2e 覆盖**。

## 3. 功能点

- **F1 看板聚合接口**：`GET /api/dashboard?start=&end=`（`start` / `end` 可空，缺省「本月 1 号 → 今天」）→ `DashboardDto`（KPI + 趋势 + TOP）。
- **F2 KPI**：按 `design.md` §0.1 口径汇集（区间额 vs 时点值分别界定）。
- **F3 趋势**：近 12 个月（含当前月）月度销售 / 采购净额。
- **F4 TOP 榜**：销售 TOP 商品 / TOP 客户（金额降序，前 10）。
- **F5 前端**：`views/Dashboard/DashboardView.vue`（区间选择 + KPI 卡片 + `a-` 图表 + TOP 表）；菜单「报表」分组续行「经营看板」。
- **F6 e2e**：建数据 → 看板显示 KPI / 趋势 / TOP；区间切换生效。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（各指标口径、区间边界、空数据不报错）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `dashboard.spec.ts`）。
3. 手工验证：
   - 建采购 / 销售 / 收付款数据后，看板 KPI 与 `025` / `023` / `034` 对应页面**数值一致**。
   - 切换区间（本月 / 本年 / 自定义）趋势与 TOP 随之变化。
   - 空账套打开看板：显示 0 而非报错。
4. 口径单一：每个指标只在 `design.md` §0.1 登记一次「来源口径指针」，不复制 `025` / `026` / `023` / `034` 正文。
5. 联动：`025` §0.2 菜单续行「经营看板」；`028` §0.2 **无新增权限点**（复用 `reports.view`）。

## 5. 范围外（不做）

- **自定义看板 / 拖拽组件 / 保存视图**：固定布局，不做 BI 化。
- **下钻到明细**：卡片不做点击下钻（既有点位：库存查 `014`、报表查 `025`）。
- **新口径指标**（如客单价、复购率、周转天数、账龄分析）：只汇集既有口径；新指标另立。
- **预测 / 同环比告警 / 目标达成**：不做。
- **导出 / 打印**：看板不做导出（如需复用 `027` 另评）。
- **移动端适配 / 大屏投屏**：不做。
- **数据权限**：看板全组织可见（`046` §0.2 已将报表列为「不约束」）。
