# 需求规格：期初建账与期末结转（erp-gl-close）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P7 内核收口与运营**项；`033-erp-general-ledger` 的**收口缺口**（`033` 让总账"能出报表"，本规格让总账"能建账、能结账、能年结"）。
> 依赖：`033`（期间 / 凭证 / 分录 / 报表取数 / `Profit` 映射键）、`031`（会计科目 / 预置科目）、`028`（权限）。
> 范围克制：只做**期初余额录入 + 期末损益结转 + 年末结转**；不做反结账、多账簿、合并报表、报表项目自定义。

## 1. 背景

`033` 建成了总账骨架（凭证 / 期间 / 期末结转字段 / 三大报表），但存在三处"上线即卡住"的缺口：

- **没有期初建账**：`033` §0.4 把科目余额表「期初」定义为"`start` 前全部 `Posted` 分录的净额"——可账套刚启用时**没有任何分录**，历史科目的期初余额（如既有银行存款、存货）无处录入，报表期初恒为 0。
- **没有期末损益结转**：损益类科目（收入 / 成本费用）月末不结转到「本年利润」（`033` §0.3 的 `Profit` 键已预置 `4103 本年利润`），导致损益类科目余额长期挂账、跨月累计，利润表只能"看发生额"而无法"看结转"。
- **没有年结**：年末「本年利润」无处结转至「利润分配」，次年利润与本年混同。

本规格补上这三项，构成"建账 → 记账 → 结转 → 结账 → 年结"的完整账期闭环。

## 2. 目标

1. **期初建账**：按科目录入期初余额（借方 / 贷方方向 + 金额），**借贷合计平衡**校验；只在账套**尚无业务凭证**时允许（一次性窗口）。
2. **期末损益结转**：按期间将损益类科目净发生额结转至本年利润，生成 `SourceType = ProfitCarry` 凭证；**幂等**（同期间不可重复结转）。
3. **结账闸门**：期间结账（`033` 既有动作）前**必须已结转损益**，否则拒绝。
4. **年末结转**：将「本年利润」余额结转至「利润分配—未分配利润」，生成 `SourceType = YearCarry` 凭证；前置为当年 1–11 月已结账。
5. **报表取数联动**：科目余额表 / 资产负债表「期初」改为「期初余额表净额 + `start` 前分录净额」（改造 `033` §0.4）。
6. **前端**：期初余额录入、结转 / 年结入口；**e2e 覆盖**。

## 3. 功能点

- **F1 期初余额录入**：`GET /api/opening-balances`（按科目返回期初 + 借贷合计）、`PUT /api/opening-balances`（全量提交，借贷平衡校验）；已有业务凭证 → `40176`。
- **F2 损益结转**：`POST /api/accounting-periods/{id}/carry-profit`（按 `033` §0.4 取损益类净额 → 生成 `ProfitCarry` 凭证）；重复 → `40177`；无损益发生额 → `40178`。
- **F3 结账闸门**：改造 `033` 的期间结账——该期间损益未结转 → `40179`。
- **F4 年末结转**：`POST /api/accounting-periods/{year}/carry-year`（本年利润 → 利润分配）；前置不满足 → `40180`。
- **F5 科目 / 映射扩充**：新增预置科目 `4104 利润分配`（`031` 种子）；`033` §0.3 映射键续行 `RetainedEarnings`。
- **F6 前端**：期初余额录入抽屉（科目余额表工具条）；结转 / 年结入口（期间管理）；**e2e 覆盖**建账 → 结转 → 结账 → 年结。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（期初平衡校验、结转幂等、结账闸门、年结前置与结果）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `gl-close.spec.ts`）。
3. 手工验证：
   - 空账套录期初余额（借 = 贷）→ 保存成功；再录（不平衡）→ `40000`；产生业务凭证后再录 → `40176`。
   - 有损益发生额的期间结转 → 生成 `ProfitCarry` 凭证、损益类科目余额清零、本年利润增加；重复结转 → `40177`。
   - 未结转损益直接结账 → `40179`；结转后结账成功。
   - 1–11 月结账后年末结转 → 生成 `YearCarry` 凭证、本年利润清零、利润分配增加。
4. 口径单一：期初取数口径、结转模板、结账 / 年结前置只在 `design.md` §0 定义一次；损益判据引用 `033` §0.4。
5. 联动：`031` §2.4 预置科目续行、`033` §0.3 / §0.4 续行与修订、`028` §0.2 **无新增权限点**、`ROADMAP` §6 错误码占用续行。

## 5. 范围外（不做）

- **反结账 / 反年结（取消结账）**：一旦结账不可逆（如需调整走下一期间）；如确需另行评估。
- **多账簿 / 多账套 / 合并报表**：单账套；多账套见 `057` / `058`（待评估）。
- **自定义报表项目 / 报表格式配置**：报表按一级科目固定列示（`033` §0.4 不变）。
- **期初建账的库存 / 往来联动**：库存期初沿用 `020`（库存盘点 / 期初建账），往来期初不单独录入（本期只做科目维度）。
- **汇兑损益 / 结转汇兑差额**：无多币种（`058` 待评估）。
- **自动结账（定时结账）**：结账 / 结转均为人工触发。
- **结账前的凭证完整性整套检查**（如必录现金流量项）：只做「损益已结转」这一项闸门。
