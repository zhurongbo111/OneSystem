# 需求规格：库存查询（erp-inventory-query）

## 0. 进销存功能组定位

本规格是**进销存（ERP）功能组**的库存查询页面，消费 erp-product 建立的库存台账：

| 子规格 | 内容 | 依赖 |
|---|---|---|
| erp-product | 商品分类 / 商品档案 / 库存台账（Inventory 表 + 原子增减 API） | 无 |
| erp-partner | 往来单位（供应商 / 客户） | 无 |
| **erp-inventory-query（本规格）** | 库存查询独立菜单页（只读列表 + 低库存提醒） | erp-product |
| erp-purchase | 采购入库单 | erp-product + erp-partner |
| erp-sale | 销售出库单 | erp-purchase（单据域共用约定）+ erp-product + erp-partner |

前置条件：erp-product 已交付（`Inventory` 表、`IInventoryRepository` 已存在，商品 / 分类接口可联调）。本规格仅**读取**库存台账，不引入新的表或实体。

## 1. 背景

进销存 MVP 中，库存的写入全部由采购入库（erp-purchase）与销售出库（erp-sale）驱动，商品管理页（erp-product）仅展示商品维度的当前库存。运营 / 仓管需要一个**以库存为中心**的独立查询视角：

- 快速查看所有启用商品的当前库存，按编码排序；
- 库存低于安全库存阈值的行标红提醒（低库存补货预警）；
- 库存为 0 的商品也展示（便于发现缺货）。

本规格只做**只读查询**，不提供任何库存写入 / 调整入口（盘点、期初建账、手工调库存均在范围外）。

## 2. 目标

1. 独立**库存查询**页：展示所有**启用商品**的当前库存，支持按关键词（编码 / 名称）/ 分类筛选，按商品编码排序；库存 < 安全阈值（且阈值 > 0）时该行库存数字标红并显示「低于安全库存」标签；库存为 0 的商品也展示。
2. 后端交付 `GET /api/inventory` 只读分页查询接口（基于 erp-product 的 `Inventory` / `Products` 联查）。
3. 侧边菜单「库存」分组下提供「库存查询」子项。

## 3. 功能点

- **F1 库存查询列表**：分页查询，展示所有**启用商品**的库存行；每行含编码 / 名称 / 分类 / 单位 / **当前库存** / 安全阈值 / 最近变动时间；支持按关键词（编码 / 名称模糊）、分类筛选；按商品编码升序；返回总数。
- **F2 低库存提醒**：库存 < 安全阈值且阈值 > 0 时，该行库存数字标红并显示 `a-tag warning`「低于安全库存」；阈值为 0 不提醒（避免零库存商品全量标红）；库存为 0 且阈值 > 0 时同样提醒。
- **F3 前端菜单**：侧边菜单「库存」分组下提供「库存查询」子项（分组结构唯一来源见 `specs/025-erp-report/design.md` §0.2）。

## 4. 验收标准

1. `cd backend && dotnet build` 成功（net8.0）；`dotnet test` 全部通过。
2. `GET /api/inventory` 仅返回**启用商品**的库存行（停用商品不出现，即使其库存非 0）。
3. 关键词 / 分类筛选正确；分页正确；按商品编码升序。
4. `isBelowSafetyStock` 映射：`safetyStock > 0 && stockQuantity < safetyStock`；阈值为 0 → false；库存 = 阈值 → false；库存为 0 且阈值 > 0 → true。
5. 每行返回 `code` / `name` / `categoryName` / `unit` / `stockQuantity` / `safetyStock` / `updatedAt` / `isBelowSafetyStock`。
6. 前端「库存查询」页：只读列表，关键词 / 分类筛选 + 搜索 / 重置 + 分页；低库存行标红 + 标签；操作列无（纯只读）。
7. 侧边菜单「库存」分组下「库存查询」可达。
8. `cd frontend && npm run build`、`npm run lint` 通过；`npm run test:e2e` 通过（含库存查询用例：筛选 → 低库存行标红断言 → 停用商品不出现在库存列表）。
9. 代码与 `AGENTS.md`、backend / frontend 专项规则一致（分层、命名、注释语言、统一响应与错误码、字段约束单一来源、按钮 loading 约定）。

## 5. 范围外（不做）

- 库存写入 / 调整入口（盘点、期初建账、手工调库存、库存调拨）。
- 多仓库 / 多批次 / 保质期。
- 库存流水 / 变动历史查询（本规格只展示当前值与最近变动时间）。
- 库存预警通知（站内信 / 邮件 / 企微推送）。
- 导出（首期不做，后续按需补充）。
