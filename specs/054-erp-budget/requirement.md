# 需求规格：预算管理（erp-budget）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P8 深化**项（**待评估**：须业务场景确认后启用）；`ROADMAP` §7 原「预算 / 固定资产 / 费用报销」范围外项之一，本轮改列待评估。
> 依赖：`031`（科目）、`033`（凭证 / 期间 / 取数口径）、`028`（权限）。
> 范围克制：只做**预算编制 + 预算执行对比（预算 vs 实际）**；**不做控制 / 拦截 / 审批 / 多版本 / 多维度（部门 / 项目）**。

## 1. 背景

费用侧入账后（`052` 费用报销、`053` 折旧等），"花了多少"有了账，但"该花多少"没有载体：

- 缺少年度 / 月度费用预算，无法回答"某科目预算多少、实际多少、超没超"。
- `033` 已有按期间的科目发生额取数口径，预算执行数可直接复用，无需新取数逻辑。
- 本规格以**最轻**的方式补齐预算：编预算 + 看执行，**不做硬控制**（拦截会牵动各单据写入路径，投入大且易误伤业务）。

## 2. 目标

1. **预算编制**：按「会计科目（费用类末级）× 年 × 月」编制预算额；支持批量按月录入、年度合计自动汇总。
2. **执行对比**：按年展示各科目 12 个月的「预算 / 实际 / 差异 / 执行率」，实际取 `033` 该科目该期间的净发生额。
3. **可改**：预算可反复修改（期间已结账的月份不可改 → `40154` 复用）。
4. **权限与菜单**：权限点续行 `028` §0.2（`budgets.*`）；菜单「财务」分组续行（`025` §0.2）。
5. **前端**：预算编制 / 执行对比单页；**e2e 覆盖**。

## 3. 功能点

- **F1 预算编制**：`GET /api/budgets?year=`（按科目返回 12 月预算）、`PUT /api/budgets`（批量提交，全量覆盖所选科目 × 月份）。
- **F2 执行对比**：`GET /api/budgets/execution?year=`（各科目逐月 预算 / 实际 / 差异 / 执行率）。
- **F3 科目校验**：预算科目须为**损益类末级启用**（否则 `40191`）；期间已结账的月份不可改（`40154`，`033`）。
- **F4 权限与菜单**：`028` §0.2 续行 `budgets.*`；`025` §0.2「财务」分组续行。
- **F5 e2e**：编预算 → 发生费用（报销 / 凭证）→ 执行对比显示实际与差异；改已结账月份 `40154`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（科目校验、执行取数、结账月份拒绝）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `budget.spec.ts`）。
3. 手工验证：
   - 为「管理费用」编 1 月预算 10,000 → 发生 6,000 费用 → 执行对比显示预算 10,000 / 实际 6,000 / 差异 4,000 / 执行率 60%。
   - 修改已结账月份的预算 → `40154`。
   - 预算科目选非损益类 → `40191`。
4. 口径单一：预算科目范围、执行数取数口径只在 `design.md` §0 定义一次（执行口径引用 `033` §0.4）。
5. 联动：`028` §0.2 续行、`025` §0.2「财务」分组续行、`ROADMAP` §6 错误码续行、§7 条目改列待评估。

## 5. 范围外（不做）

- **预算控制 / 超预算拦截 / 硬性阻止单据**：只做"看"，不做"拦"；接拦截需改各单据写入路径，另评。
- **预算审批 / 多级签核**：不做。
- **预算版本 / 调整单 / 追加流程**：单一版本，直接改数。
- **多维度预算**（部门 / 项目 / 成本中心）：本期只按会计科目（`033` 无辅助核算维度）。
- **收入 / 资产负债预算**：只做费用类科目（损益类）。
- **预算预警通知（接入 `041`）**：不做。
- **预算导出 / 打印**：一期不做。
