# 需求规格：财务主数据（erp-finance-master）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P2 财务闭环**第一项；`033-erp-general-ledger`（总账）与 `032-erp-invoice`（发票）的**硬前置**。
> 依赖：无（纯主数据）；被 `033`（科目 / 税率）、`032`（税率）消费。

## 1. 背景

现状**没有任何"会计"概念**：

- `023` 收付款、`026` 成本、`025` 报表输出的都是**业务口径金额**，没有会计科目，无法形成账簿、无法出财务报表——这是"进销存"与"ERP"的结构性缺口。
- `032-erp-invoice`（已起草）需要"税率"来算税额，但系统没有税率字典，只能每次手填。
- `033` 总账的凭证分录必须落到**会计科目**上，**科目表因此是总账的硬前置**。

本规格只做两块**会计主数据**：**会计科目**（树）与**税率**（字典）。**不做**总账 / 凭证（`033`）、**不做**银行账户 / 资金（`034`）、**不做**币种 / 多账套。

## 2. 目标

1. **会计科目**：维护科目树（编码 / 名称 / 类别 / 余额方向 / 上级 / 状态），支持新增下级、编辑、启停；**末级科目才可记账**；删除受"有子科目 / 已被凭证引用"保护。
2. **税率字典**：维护税率（编码 / 名称 / 税率百分比 / 状态），供发票与凭证计量税额。
3. **预置标准科目**：首次初始化预置一套最小标准科目表（资产 / 负债 / 权益 / 成本 / 损益），可编辑（预置科目不可删，可改名 / 停用）。
4. **权限与菜单**：权限点续行至 `028` §0.2（`accounts.*` / `taxRates.*`）；新建「财务」菜单分组（`025` §0.2 续行）。
5. **前端**：新增「会计科目」（树）与「税率」（列表）两页。

## 3. 功能点

- **F1 会计科目树**：`GET /api/accounts`（树）；新增 / 编辑 / 删除 / 启停；`Code` 全局唯一（`40149`）；有子科目或已被凭证引用 → 禁止删除（`40150` / `40153`）；末级判定 = 无子科目（派生）。
- **F2 税率字典**：`GET /api/tax-rates`（分页 + 关键词 / 状态筛选）；新增 / 编辑 / 删除 / 启停；`Code`（`40151`）、`Name`（`40152`）唯一。
- **F3 预置科目种子**：`DatabaseInitializer` 幂等预置标准科目（§`design` §2.5），已存在则跳过。
- **F4 权限与菜单**：§0 权限点续行至 `028`；「财务」分组续行至 `025`。
- **F5 e2e 覆盖**：建科目树 → 编码重复 `40149` → 删除有子科目 `40150` → 建税率 → 编码 / 名称重复 `40151` / `40152` → 预置科目可见。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（科目树 / 末级判定 / 删除保护 / 预置幂等、税率唯一性等单测）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `finance-master.spec.ts`）。
3. 手工验证：预置科目表可见；新增下级科目形成树；非末级科目在总账（`033`）不可记账（本规格只提供"末级"判据）；删除有子科目的科目 → `40150`。
4. 税率：编码 / 名称重复 → `40151` / `40152`；税率值 2–4 位小数（如 `13`、`13.5`、`9.0000`）。
5. 口径单一：科目类别 / 方向取值、末级判定、唯一性范围只在 `design.md` §0 定义一次。
6. 联动：`028` §0.2 续行权限点；`025` §0.2 新增「财务」分组；`032` `design.md` 加"税率引用演进"注记（可改为从字典取）。

## 5. 范围外（不做）

- **总账 / 凭证 / 期间 / 财务报表**：`033-erp-general-ledger`。
- **银行账户 / 资金日记账 / 票据**：`034-erp-cash`。
- **多币种 / 汇率 / 外币核算**：单币种（人民币）。
- **多账套 / 多法人主体核算**：单主体（`ROADMAP` §7）。
- **科目辅助核算**（部门 / 项目 / 往来 / 商品辅助项）：一期科目为纯科目。
- **期初余额录入与试算平衡**：`033` 处理。
- **报表项目映射维护**：`033` 内置简化映射，不做可配置映射表。
- **科目 / 税率的历史版本与生效时间**：单值（改了即覆盖），变更留痕走 `029`。
