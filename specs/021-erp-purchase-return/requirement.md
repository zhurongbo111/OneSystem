# 需求规格：采购退货（erp-purchase-return）

> 进销存扩展路线（`specs/ROADMAP.md`）已完成（单据与资金闭环）；本规格同时定义**退货单域共用约定**，`022-erp-sale-return` 继承。

## 1. 背景

现状采购侧只有「作废」（`015-erp-purchase`）：作废面向**误录**，把单据从业务中抹掉（状态置为已作废），并不表达真实业务事件。

真实场景是货已入库、已入账，之后要**退回供应商**：库存要减、应付要冲减、退货本身要留凭证。用「作废原采购单」来冒充退货有两个问题——它抹掉了采购发生的事实（历史采购数据、供应商往来口径失真），也无法表达「部分退回」。

`019` 的库存流水已让每次库存变动可追溯，退货造成的出库同样需要落流水。

## 2. 目标

1. 新增**采购退货单**：选择供应商 + 商品明细（数量 / 单价）→ 保存即生效（**减少库存**并冲减应付口径），保留完整凭证。
2. 一步式与可作废：不可编辑；作废后库存回冲（退回的货「收回」到账上）。
3. 库存不足时拒绝开单（退回实物必须账上有货），返回 `40103`。
4. 每次退货与作废都在同一事务内写库存流水（新增两种变动类型）。
5. 提供退货列表（单号 / 供应商 / 日期范围 / 结算状态筛选 + 分页）、开单页、详情页（含作废与结算切换）。

## 3. 功能点

- F1 新增 `PurchaseReturns` / `PurchaseReturnItems` 表与实体（字段见 `design.md` §2）。
- F2 新增用例 `PurchaseReturns/CreatePurchaseReturn`：供应商校验 → 商品校验 → 金额后端重算 → **先扣库存**（`TryDecrementAsync`，失败 `40103` 回滚）→ 落单 + 明细 → 逐行写流水（同一事务）。
- F3 新增用例 `VoidPurchaseReturn`（作废回冲 + 反向流水）、`UpdatePurchaseReturnSettlement`（结算状态切换）、`GetPurchaseReturns`（列表）、`GetPurchaseReturnById`（详情）。
- F4 前端「采购退货」页（`/purchase-returns` 列表 + `/purchase-returns/new` 开单 + `/purchase-returns/detail/:id` 详情，含作废与结算）。
- F5 库存流水（`019`）新增变动类型：采购退货、采购退货作废（文案与颜色在 `019` design §0 表内续行）。
- F6 e2e 覆盖：开退货单 → 库存减少且流水 `-N`「采购退货」；作废 → 库存回冲且流水 `+N`「采购退货作废」；库存不足开单被拒。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（含 5 个用例的单测与流水写入 / 回滚断言）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿。
3. `cd frontend && npm run test:e2e` 全量通过（含新增 `purchase-return.spec.ts` 与采购 / 销售 / 库存 / 流水既有用例回归）。
4. 手工验证：
   - 某商品库存 20，开退货单退 5 → 库存 15，流水出现 `-5`「采购退货」（来源本单号）；该单作废 → 库存 20，流水出现 `+5`「采购退货作废」。
   - 退货数量 > 当前库存 → 提示库存不足（`40103`，含商品名与当前 / 需要数量），库存与单据均无变化。
   - 列表筛选（单号 / 供应商 / 日期范围 / 结算状态）与详情（快照字段、明细）正确；结算切换可用。
5. 对账口径仍成立：任一商品 `Σ 流水变动量 == Inventory.Quantity`（含退货与作废后）。
6. 事务性：开单过程中任一环节失败（库存不足 / 商品停用 / 供应商停用）时，**库存与流水均无变化、单据不落库**（单测覆盖 `RollbackAsync`）。

## 5. 范围外（不做）

- **关联原采购单 / 按原单部分退货**：需要跟踪「已退数量」并校验累计不超原单数量，属后续增强；本规格退货单独立开具（备注可写原单号）。
- **退款 / 应付冲抵单据**：退货对资金侧的影响统一由 `023-erp-settlement` 的应收应付与收付款处理。
- **换货（退 + 换）**：等价于退货单 + 采购单两步操作，不新增单据类型。
- **退货原因字典**：先用备注自由文本（字典属主数据治理）。
- **分仓退货**：多仓见 `038-erp-multi-warehouse`（届时退货单需带仓库维度与退货入库仓）。
- **导入 / 导出 / 打印**：`027-erp-export`。
