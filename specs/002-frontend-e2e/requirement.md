# 需求规格：frontend-e2e（前端集成测试自动化）

## 1. 背景

`project-scaffold` 的登录 / 首页集成验证此前靠人工（AI 浏览器）走查：需手动起前后端服务、手动点击操作，无法重复执行，也无法纳入 CI。

## 2. 目标

- 用 Playwright 将前端核心集成测试流程自动化，一条命令 `npm run test:e2e` 跑通。
- 集成测试保持直连真实 dev 后端（不打 mock），与前端规则「不单写单元测试、以联调为准」一致。

## 3. 功能点

- **FP1**：`npm run test:e2e` 一键运行 e2e 集成测试。
- **FP2**：覆盖用例：登录成功 → 首页展示当前用户 → 退出登录回登录页；未登录直接访问首页被路由守卫重定向到登录页。
- **FP3**：前置服务未启动时，测试开始前给出明确报错（指明需启动哪些服务），不产生误导性失败。

## 4. 验收标准

- [ ] 前后端 dev 服务运行中时，`npm run test:e2e` 全部用例通过。
- [ ] 后端未启动时，输出明确的「需先启动后端」提示。
- [ ] AGENTS.md 第 6 节测试策略、前端规则第 8 节同步更新。
