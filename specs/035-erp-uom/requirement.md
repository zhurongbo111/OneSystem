# 需求规格：计量单位（erp-uom）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P3 主数据与政策**第一项，主数据补全。
> 依赖：`012-erp-product`（商品档案，改造其"单位"字段为引用字典）。
> 范围克制：一期只做**单位字典 + 商品单位引用**；**多单位换算**与**编码规则**列为范围外（见 §5）。

## 1. 背景

现状 `Product.Unit`（`varchar(10)`）是**自由文本**：

- 同一单位写法不一（「个」/「只」、大小写、错别字），统计与开单口径难统一；单据明细的 `Unit` 快照亦取自该文本。
- `ROADMAP` §3 把"计量单位 / 编码规则"列为主数据补全项，单位字典是其中之一。

本规格把"单位"从自由文本升级为**字典引用**，为后续"多单位换算"打好基础。

## 2. 目标

1. **单位字典**：维护计量单位（编码 / 名称 / 状态 / 备注），支持新增 / 编辑 / 启停；被商品引用禁止删除。
2. **商品单位引用**：商品「计量单位」由自由文本改为**选择单位字典**；保留单位名**快照**（列表展示免 join），历史单据 `Unit` 快照不变。
3. **权限与菜单**：权限点续行至 `028` §0.2（`units.*`）；菜单续行至 `025` §0.2「基础档案」分组。
4. **前端**：新增「计量单位」页（列表 + 抽屉）；`012` 商品表单的「单位」改为下拉选择。

## 3. 功能点

- **F1 单位字典**：`GET /api/units`（分页 + 关键词 / 状态筛选）；新增 / 编辑 / 删除 / 启停；`Code`（`40163`）、`Name`（`40164`）唯一；被商品引用 → 禁止删除（`40165`）。
- **F2 单位下拉**：`GET /api/units/picks`（启用的精简列表，供商品表单下拉）。
- **F3 商品单位改造（`012`）**：`Products` 增 `UnitId`（FK → `Units`，NOT NULL）；`Unit` 列保持为名称**快照**（`varchar(20)`）；商品新增 / 编辑请求的单位改为 `unitId`；迁移把现有 `Products.Unit` 文本去重后建单位并回填 `UnitId`。
- **F4 权限与菜单**：§0 续行 `028` / `025`（「基础档案」分组）。
- **F5 e2e 覆盖**：建单位 → 编码 / 名称重复 `40163` / `40164` → 商品表单选单位 → 删除被引用单位 `40165`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（单位唯一 / 删除保护、商品单位引用 / 迁移回填等单测）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `unit.spec.ts` + `product.spec.ts` 回归）。
3. 手工验证：新建单位「个」「箱」；商品表单单位下拉可选；编码 / 名称重复 → `40163` / `40164`；删除被商品引用的单位 → `40165`。
4. 迁移：既有商品的 `Unit` 文本在迁移后对应生成单位记录并完成回填（无数据丢失）；商品列表单位列正常显示。
5. 口径单一：单位唯一性范围与商品单位引用规则只在 `design.md` §0 / §2 定义一次。
6. 联动：`012` `design.md` 加「演进（erp-uom）」注记（`Unit` → `UnitId` + 快照）；`028` §0.2 / `025` §0.2 续行。

## 5. 范围外（不做）

- **多单位换算**（箱 / 包 → 基本单位、换算率、开单按辅助单位换算）：需改**库存与单据数量语义**（库存以基本单位记账、开单可选辅助单位），改造面大，**建议独立规格**。
- **编码规则**（单据 / 档案编号规则可配置）：`ROADMAP` 原与单位同项，本规格**不含**，待独立规格评估。
- **单位分组 / 单位类别、度量衡属性**（重量 / 体积 / 是否为小数的数量单位）：不做。
- **商品条码 / 多规格 / 多属性**：不做。
- **单位的历史版本与生效时间**：单值（改了即覆盖）。
- **小数数量的单位**（如 kg）：一期数量仍为整数（沿用 `ProductFieldConstraints.QuantityMinValue/MaxValue` 的整数语义）。
