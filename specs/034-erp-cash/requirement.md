# 需求规格：资金出纳（erp-cash）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P2 财务闭环**收尾项。
> 依赖：`023-erp-settlement`（收付款单 —— 资金流水的来源）；`033`（总账，弱依赖：凭证仍用映射科目，不区分具体账户）。
> 本规格**小改造** `023`：收付款单增可空「资金账户」关联。

## 1. 背景

`023` 只记录收付款单的**结算方式**（现金 / 银行转账 / 其他），没有**资金账户**概念：

- 公司有多个银行账户，无法按账户掌握"每个账户收了多少、付了多少、余额多少"；`Method = 银行转账` 不区分具体账户。
- 出纳需要一本**资金日记账**（按账户 / 日期的收支流水与余额），现在只能靠人工从收付款列表汇总。

本规格在 `023` 之上补**资金账户 + 资金日记账**：账户作为主数据，收付款单关联账户，日记账与余额由单据派生。**不做**票据管理、银行对账（范围外）。

## 2. 目标

1. **资金账户**：维护账户（编码 / 名称 / 类型（现金 / 银行）/ 开户行 / 账号 / 初始余额 / 状态）；现金与银行账户分类型管理。
2. **收付款关联账户**：`023` 收付款单增可空「资金账户」；结算方式与账户类型需匹配（现金 ↔ 现金账户，银行转账 ↔ 银行账户）。
3. **资金日记账**：按账户 + 日期范围查询收支流水（来源收付款单），含**收 / 付 / 余额**三列与期初 / 期末。
4. **资金总览**：各账户当前余额（初始余额 + Σ 收 − Σ 付）汇总。
5. **权限与菜单**：权限点续行至 `028` §0.2（`bankAccounts.*` / `cashJournals.view`）；菜单续行至 `025` §0.2「财务」分组。
6. **前端**：新增「银行账户」（列表）与「资金日记账」（列表 + 总览）两页；`023` 收付款表单追加账户选择。

## 3. 功能点

- **F1 资金账户**：`GET /api/bank-accounts`（分页 + 关键词 / 类型 / 状态筛选）；新增 / 编辑 / 删除 / 启停；`Code` 全局唯一（`40160`）；被收付款单引用 → 禁止删除（`40161`）。
- **F2 账户余额**：`GET /api/bank-accounts/summary`（各账户余额 = 初始余额 + Σ 收款 − Σ 付款）。
- **F3 资金日记账**：`GET /api/cash-journals?bankAccountId=&start=&end=`（按日期升序；含期初余额、每笔收 / 付与结余）；只读。
- **F4 收付款关联账户（`023` 改造）**：`Settlement` 增可空 `BankAccountId`；`CreateSettlement` 表单追加账户选择；校验类型匹配（`40162`）。
- **F5 权限与菜单**：§0 续行 `028` / `025`。
- **F6 e2e 覆盖**：建现金 / 银行账户 → 收款关联银行账户 → 资金日记账出现该笔、余额正确 → 类型不匹配 `40162` → 删除被引用账户 `40161`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（账户唯一 / 删除保护 / 类型匹配、日记账与余额口径等单测）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `cash.spec.ts` + `settlement.spec.ts` 回归）。
3. 手工验证：
   - 账户 A 初始余额 1000，收款 500 关联 A、付款 300 关联 A → 日记账显示期初 1000 / 收 500 / 付 300 / 期末 1200；总览余额 1200。
   - 现金账户关联"银行转账"结算单 → `40162`。
   - 删除被收付款引用的账户 → `40161`。
4. 口径单一：账户类型与结算方式的匹配规则、余额口径只在 `design.md` §0 定义一次。
5. 联动：`023` `design.md` 加「演进（erp-cash）」注记（`Settlement` 增 `BankAccountId`）；`028` §0.2 / `025` §0.2 续行。

## 5. 范围外（不做）

- **票据管理**（应收 / 应付票据、票据背书 / 贴现）：另行评估。
- **银行对账 / 银行流水导入**：不做与银行系统的对接与对账。
- **资金计划 / 预算 / 资金调拨**：不做。
- **账户间转账单**：可用"付款 + 收款"两条单据表达，一期不做专用转账单（如需另立规格）。
- **多币种账户 / 汇率**：单币种（人民币）。
- **总账凭证按账户细分**：`033` 的自动凭证用 `Bank` 映射科目，不区分具体账户（如需按账户核算，用辅助核算演进）。
- **账户收支的日终 / 月结**：不做。
- **出纳经办 / 复核流程**：随 `042` 审批路线另行评估。
