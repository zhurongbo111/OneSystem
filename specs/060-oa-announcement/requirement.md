# 需求规格：公告通知（oa-announcement）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P10 办公协同**首项（边界与决策见 `ROADMAP` §6.11）；OA 协同域的「信息触达」入口。
> 依赖：`028`（权限 / 默认拒绝）、`030`（部门树、员工↔账号绑定）、`041`（站内信通道 `INotificationWriter` 与顶栏铃铛）。
> 范围克制：只做**公告发布与阅读回执**；不新建消息通道、不新建审批引擎；不做附件 / 富文本 / 评论 / 定时发布 / 外部推送（见 §5）。

## 1. 背景

`041` 已建立站内信通道（`Notifications` 表 + `INotificationWriter` + 顶栏铃铛 + 站内消息页），但它服务的是**系统生成的定向提醒**（库存预警、审批待办）：内容由规则产出、接收人由权限点圈定，**没有「人主动发布、按范围触达、可回看并统计已读」的公告能力**。

`ROADMAP` §1 把 OA 定位为「复用内核」：本规格**不新建消息通道、不新建审批引擎**，只补一个业务对象（公告）+ 阅读回执，发布时经 `041` 的 `INotificationWriter` 复用既有触达路径。

## 2. 目标

1. **公告编辑**：标题 + 正文 + 可见范围 + 置顶 + 有效期；草稿态可改。
2. **发布与撤回**：草稿 → 已发布（对可见范围可见并发站内信）→ 可撤回；撤回为终态。
3. **可见性**：按可见范围（全员 / 指定部门）过滤列表与详情；范围外用户访问详情 → `40300`。
4. **阅读回执**：查看即记已读；管理侧可见「已读人数 / 应读人数」与未读名单。
5. **前端**：公告列表（状态 / 未读筛选）+ 详情页 + 管理侧新建 / 编辑 / 发布 / 撤回 / 删除；菜单分组「办公 → 公告」。
6. **e2e 覆盖**发布 → 可见 → 已读的完整用户路径。

## 3. 功能点

- **F1 公告管理**：`POST /api/announcements`、`PUT /api/announcements/{id}`、`DELETE .../{id}`、`GET /api/announcements`、`GET .../{id}`；字段 = 标题 / 正文 / 可见范围 / 置顶 / 有效期。
- **F2 状态流转**：`POST .../{id}/publish`（草稿 → 已发布）与 `POST .../{id}/withdraw`（已发布 → 已撤回）；**仅草稿可编辑 / 删除 / 发布**，仅已发布可撤回。
- **F3 触达**：发布时向可见范围内**启用**用户经 `INotificationWriter` 写站内信（`NotificationType.Announcement = 6`，实现时续行 `041` §2.1），`LinkRouteName = announcements` + `LinkQuery = {"id":"<公告id>"}`；发信失败只记日志，不影响发布结果。
- **F4 可见性与已读**：列表 / 详情按可见范围过滤（部门含下级、未绑定员工仅 `All` 可见）；`POST .../{id}/read` 记当前用户已读（幂等）；详情返回 `readCount` / `audienceCount` 与未读名单。
- **F5 前端**：`views/AnnouncementManagement/`（列表 + 详情 + 表单抽屉）、`api/announcement.ts`；菜单新增顶级分组「办公」。
- **F6 e2e**：新增 `e2e/announcement.spec.ts`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（状态机白名单、可见范围过滤、已读幂等、发信调用与失败降级）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run e2e:run` 全量通过（新增 `announcement.spec.ts`）。
3. 手工验证：
   - 管理员发布「全员」公告 → 普通用户在顶栏铃铛收到站内信，点击跳转公告详情；
   - 用户打开详情即记已读 → 管理侧已读人数 +1，未读名单少一人；
   - 范围外用户直接访问详情 URL → `40300`；
   - 已发布公告的「编辑 / 删除」入口不可用，撤回后为终态。
4. 口径单一：可见范围取值、状态机、已读判据只在 `design.md` §0 定义一次。
5. 联动（实现时）：`041` §2.1 续行 `NotificationType.Announcement = 6`（附演进指针）；`028` §0.2 续行 `announcements.*`；`029` §0.1 续行资源 `Announcement`。

## 5. 范围外（不做）

- **附件 / 富文本 / 图片**：首期正文为纯文本（保留换行）。
- **评论 / 点赞 / 回复**：不做。
- **定时发布 / 定时撤回**：发布为即时动作。
- **外部推送**（邮件 / 短信 / 企业微信）：站内信是唯一通道（同 `041`）。
- **已读强制与考核**（逾期未读连带处理）：只提供回执与统计。
- **公告分类 / 标签 / 搜索历史**：不做。
