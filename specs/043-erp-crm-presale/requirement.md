# 需求规格：CRM 售前（erp-crm-presale）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P5 流程增强**项；CRM 并入主线的**轻量入口**（`ROADMAP` §1）。
> 依赖：`013`（客户 —— 商机可关联）、`030`（员工 —— 负责人）、`037`（报价单 —— 商机转化的后续，本期不做）。
> 范围克制：做**线索 + 商机 + 跟进活动**；不做完整 CRM（客户画像 / 营销自动化 / 服务工单见 `045`）。

## 1. 背景

现状系统覆盖"客户 → 订单 → 回款"的**交易侧**（`013` / `024` / `023` / `036`），但**售前侧是空白**：

- 意向客户（线索）无处登记，只能记在个人 Excel / 微信里；团队看不到"有哪些潜在客户、谁在跟"。
- 商机金额、阶段、预计成交时间没有台账，销售预测无从谈起。
- 跟进过程（电话 / 拜访 / 邮件）没有留痕。

本规格补上 CRM 的**售前侧**，与既有交易侧共用客户主数据，形成"线索 → 商机 →（报价 → 订单）"的完整链条上半段。

## 2. 目标

1. **线索（Lead）**：登记潜在客户（名称 / 联系人 / 电话 / 来源 / 负责人 / 状态），支持新增 / 编辑 / 状态流转 / 转商机。
2. **商机（Opportunity）**：客户 / 名称 / 预计金额 / 阶段（初步接洽 → 需求确认 → 方案报价 → 谈判 → 赢单 / 输单）/ 预计成交日期 / 负责人，支持新增 / 编辑 / 阶段推进。
3. **跟进活动（Activity）**：在**线索或商机**下记跟进记录（类型 / 内容 / 时间），详情内可查可增。
4. **负责人**：线索 / 商机可指派负责人（**员工**，`030`）。
5. **不产生交易影响**：线索 / 商机不锁库存、不产生资金（同报价单性质）。
6. **权限与菜单**：权限点续行至 `028` §0.2（`leads.*` / `opportunities.*`）；新建「CRM」菜单分组（`025` §0.2 续行）。
7. **前端**：线索列表 / 表单 / 详情（含活动）、商机列表 / 表单 / 详情（含活动）。
8. **e2e 覆盖**。

## 3. 功能点

- **F1 线索**：`GET /api/leads`（关键词 / 来源 / 状态 / 负责人筛选 + 分页）；新增 / 编辑 / 状态流转（新线索 → 跟进中 → 已转化 / 已废弃）；单号 `LD + yyyyMMdd + 4`。
- **F2 线索转商机**：`POST /api/leads/{id}/convert` → 生成商机、线索置「已转化」（已转化 / 已废弃不可再转，`40168`）。
- **F3 商机**：`GET /api/opportunities`（关键词 / 阶段 / 客户 / 负责人筛选 + 分页）；新增 / 编辑 / 阶段推进；单号 `OP + yyyyMMdd + 4`；`Won` / `Lost` 为终态（终态后不可改阶段，`40169`）。
- **F4 跟进活动**：`GET /api/activities?bizType=&bizId=`、`POST /api/activities`（线索 / 商机下新增跟进记录）；只增不改不删（留痕）。
- **F5 权限与菜单**：§0 续行 `028` / `025`（新建「CRM」分组）。
- **F6 e2e**：建线索 → 跟进 → 转商机 → 商机阶段推进至赢单 → 已转化线索再转 `40168` / 终态商机改阶段 `40169`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（状态流转、转商机、终态限制、活动等单测）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `crm-presale.spec.ts`）。
3. 手工验证：
   - 建线索（来源「展会」、负责人选员工）→ 详情加一条「电话」跟进 → 转商机 → 线索「已转化」且商机出现在商机列表。
   - 商机阶段推进到「赢单」→ 再改阶段 → `40169`；已转化线索再转 → `40168`。
   - 线索 / 商机不改变库存与应收（对账前后一致）。
4. 口径单一：线索 / 商机状态与来源取值、转商机规则只在 `design.md` §0 定义一次。
5. 联动：`028` §0.2 / `025` §0.2 续行。

## 5. 范围外（不做）

- **商机转报价单 / 订单**：本期只到商机赢单；转报价（`037`）与转订单的联动另行评估。
- **线索 / 商机的批量导入导出**：不做。
- **客户画像 / 客户分级 / 客户联系人管理**：不做（联系人暂为线索字段）。
- **营销活动 / 邮件群发 / 短信**：不做。
- **销售目标 / 销售预测报表**：不做（商机金额可用于后续报表）。
- **公海池 / 线索分配规则 / 撞单检测**：不做。
- **跟进提醒 / 待办**：随 `041` 站内信能力另行评估。
- **服务工单 / 售后**：`045-erp-crm-service`。
- **多处办公 / 团队组织维度过滤**：单主体（`ROADMAP` §7）。
