# 需求规格：多币种与合并报表（erp-multi-currency）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P9 组织扩展**项（**待评估**：**确有多主体 / 多币种经营时启动**）；承接 `057-erp-multi-org`。
> 依赖：`057`（多公司 / 隔离）、`033`（凭证 / 报表）、`031`（科目）、`028`（权限）。
> 范围克制：只做**币种字典 + 汇率维护 + 公司本位币 + 单据 / 凭证多币种 + 合并报表折算**；**不做内部交易抵消 / 外币折算差额（汇兑损益）/ 多账簿**。

## 1. 背景

`057` 引入多公司后，账务仍隐含"单一币种"：

- 跨境贸易要用**外币**开单 / 收付款（美元、欧元…），需要币种字典与汇率。
- 各公司**记账本位币**可能不同（境内人民币、境外美元），报表不能直接相加。
- 集团视角需要**合并报表**：把各公司报表按汇率折算到统一报告币种后合并。

本规格补上多币种与合并报表，与 `057` 共同构成多主体经营能力。

## 2. 目标

1. **币种字典**：编码（`CNY` / `USD`…）/ 名称 / 符号 / 小数位 / 启停；预置 `CNY`。
2. **汇率维护**：按「源币 → 目标币 + 生效日期」维护折算率；取"生效日期不晚于业务日期的**最新**汇率"。
3. **公司本位币**：`Company` 增本位币（`057` 表扩展）；本位币在**已有业务后不可改**（`40200`）。
4. **多币种单据**：业务单据增 `CurrencyId` + 汇率**快照**；既有金额列语义 = **本位币金额**（原币由 `本位币 ÷ 汇率` 推导，前端展示）。
5. **多币种凭证**：凭证分录增 `CurrencyId` / `ExchangeRate` 快照；金额为本位币（报表取数口径不变）。
6. **合并报表**：按报告币种折算各公司报表后合并（资产负债表 / 利润表）；**不做内部交易抵消**。
7. **前端**：币种 / 汇率维护页 + 合并报表页 + 单据币种选择；**e2e 覆盖**。

## 3. 功能点

- **F1 币种字典**：`GET/POST /api/currencies`、`PUT /{id}`、`PUT /{id}/status`；预置 `CNY`（不可删）。
- **F2 汇率**：`GET/POST /api/exchange-rates`、`DELETE /{id}`；唯一 `(FromCurrencyId, ToCurrencyId, EffectiveDate)`；缺汇率 → `40199`。
- **F3 公司本位币**：`057` 的 `Company` 增 `BaseCurrencyId`；业务发生后不可改（`40200`）；公司本位币停用币种 → `40198`。
- **F4 单据多币种**：受影响单据（`design.md` §0.2）增 `CurrencyId` + `ExchangeRate`；创建时按业务日期取汇率，缺 → `40199`。
- **F5 凭证多币种**：`VoucherEntry` 增 `CurrencyId` / `ExchangeRate` 快照（金额仍为本位币）；自动凭证沿用来源单据快照。
- **F6 合并报表**：`GET /api/reports/consolidated?year=&currencyId=`（资产负债表 / 利润表按报告币种折算合并）。
- **F7 权限与菜单**：`028` §0.2 续行 `currencies.*` / `exchangeRates.*` / `consolidatedReports.view`；`025` §0.2 续行。
- **F8 e2e**：维汇率 → 建外币单据 → 报表本位币金额正确；合并报表跨公司折算合计；缺汇率 `40199`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（汇率取值、折算、本位币保护、合并口径）。
2. 备份 `057` 隔离回归：单币种（仅 `CNY`）时行为与升级前一致。
3. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `multi-currency.spec.ts`）。
4. 手工验证：
   - 维护 `USD → CNY = 7.1`（生效某日）→ 建 USD 单据 1,000 → 本位币金额 7,100；报表按 7,100 取数。
   - 公司本位币已发生业务后修改 → `40200`；缺当日汇率 → `40199`。
   - 合并报表：公司 A（CNY）+ 公司 B（USD，折算）→ 报告币种 CNY 下合计正确。
5. 口径单一：汇率取值规则、折算口径、合并口径、金额列语义只在 `design.md` §0 定义一次。
6. 联动：`057` §0.1 / §2.1 增本位币、`033` §2.3 分录扩展、`028` §0.2 续行、`025` §0.2 续行、`ROADMAP` §6 续行、§7 条目改列待评估。

## 5. 范围外（不做）

- **内部交易抵消 / 合并抵销分录**：合并报表只做"折算相加"。
- **外币折算差额（汇兑损益）**：期末不重估、不生成汇兑损益凭证。
- **多账簿 / 平行记账**（同一业务多套账）：不做（`ROADMAP` §3 缺口保留）。
- **汇率类型（即期 / 平均 / 历史）与多汇率来源**：单一折算率（按生效日期取最新）。
- **汇率自动抓取 / 外部接口**：人工维护。
- **多币种库存成本 / 多币种资金账户余额重估**：库存与资金账户余额按本位币记录，不做外币重估。
- **报表项目自定义 / 合并层级（集团 → 分部）**：只按公司平级合并。
- **币种级小数位在金额列上的动态精度**：金额统一 `numeric(18,2)`。
