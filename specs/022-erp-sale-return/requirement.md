# 需求规格：销售退货（erp-sale-return）

> 进销存扩展路线（`specs/ROADMAP.md`）已完成（单据与资金闭环）；结构继承 `021-erp-purchase-return` §0「退货单域共用约定」。

## 1. 背景

现状销售侧只有「作废」（`016-erp-sale`），面向误录，不表达真实退货。

真实场景是货已发出、已开票或已收款，客户因质量 / 错发 / 滞销退回：库存要**增加**（货回到仓库）、应收要**冲减**、退货要有凭证。用「作废原销售单」冒充退货会抹掉销售发生的事实（销售收入与客户往来口径失真），也无法表达「部分退回」。

`019` 的库存流水已让每次库存变动可追溯，退货造成的入库同样需要落流水。

## 2. 目标

1. 新增**销售退货单**：选择客户 + 商品明细（数量 / 单价）→ 保存即生效（**增加库存**并冲减应收口径），保留完整凭证。
2. 一步式与可作废：不可编辑；作废后库存回冲（把退回入库的货「拿走」，允许冲负，与采购作废对称）。
3. 每次退货与作废都在同一事务内写库存流水（新增两种变动类型）。
4. 提供退货列表（单号 / 客户 / 日期范围 / 结算状态筛选 + 分页）、开单页、详情页（含作废与结算切换）。
5. 与采购退货保持结构同构：同一套字段语义、验收与测试口径，仅方向与往来对象不同。

## 3. 功能点

- F1 新增 `SalesReturns` / `SalesReturnItems` 表与实体（字段与 `PurchaseReturns` 同构，见 `design.md`）。
- F2 新增用例 `SalesReturns/CreateSalesReturn`：客户校验 → 商品校验 → 金额后端重算 → **库存回增**（`IncrementAsync(+quantity)`）→ 落单 + 明细 → 逐行写流水（同一事务）。
- F3 新增用例 `VoidSalesReturn`（回冲 `IncrementAsync(-quantity)` + 反向流水）、`UpdateSalesReturnSettlement`、`GetSalesReturns`、`GetSalesReturnById`。
- F4 前端「销售退货」页（`/sales-returns` 列表 + `/sales-returns/new` 开单 + `/sales-returns/detail/:id` 详情，含作废与结算）。
- F5 库存流水（`019`）新增变动类型：销售退货、销售退货作废（文案与颜色在 `019` design §0 表内续行）。
- F6 e2e 覆盖：开退货单 → 库存增加且流水 `+N`「销售退货」；作废 → 库存回冲且流水 `-N`「销售退货作废」；列表筛选与详情、结算切换可用。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（含 5 个用例的单测与流水写入 / 回滚断言）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿。
3. `cd frontend && npm run test:e2e` 全量通过（含新增 `sale-return.spec.ts` 与采购 / 销售 / 退货 / 库存 / 流水既有用例回归）。
4. 手工验证：
   - 某商品库存 10，开销售退货单退 3 → 库存 13，流水出现 `+3`「销售退货」（来源本单号）；该单作废 → 库存 10，流水出现 `-3`「销售退货作废」。
   - 退货数量允许超过当前库存（退货是入库，不设上限）；作废回冲允许冲负（货可能已被再次卖出）。
   - 列表筛选（单号 / 客户 / 日期范围 / 结算状态）与详情（快照字段、明细）正确；结算切换可用。
5. 对账口径仍成立：任一商品 `Σ 流水变动量 == Inventory.Quantity`（含退货与作废后）。
6. 事务性：开单过程中任一环节失败（客户停用 / 商品停用 / 商品不存在）时，**库存与流水均无变化、单据不落库**（单测覆盖 `RollbackAsync`）。

## 5. 范围外（不做）

- **关联原销售单 / 按原单部分退货**：需要在原单明细上跟踪「已退数量」，属后续增强；本规格退货单独立开具（备注可写原单号）。
- **退款单据 / 应收冲抵**：资金侧统一由 `023-erp-settlement` 处理。
- **换货**：等价于退货单 + 销售单两步操作。
- **退货原因字典**：先用备注自由文本。
- **退货运费 / 折让金额**：本期只支持按数量 × 单价退货，不支持额外费用科目。
- **分仓退货入库**：多仓见 `038-erp-multi-warehouse`（届时需指定退货入库仓）。
- **导入 / 导出 / 打印**：`027-erp-export`。
