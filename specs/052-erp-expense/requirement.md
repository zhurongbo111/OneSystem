# 需求规格：费用报销（erp-expense）

> ERP 全域路线（`specs/ROADMAP.md` §4.2）**P8 深化**项（**待评估**：须业务场景确认后启用）；`ROADMAP` §7 原「预算 / 固定资产 / 费用报销」范围外项之一，本轮改列待评估。
> 依赖：`033`（凭证 / 期间闸门 / 自动凭证写入通道）、`031`（费用科目）、`034`（资金账户）、`030`（员工）、`028`（权限）。
> 范围克制：只做**费用报销单 + 审批 + 生成凭证**；不做预算控制、差旅标准、发票查验、多级审批、借款冲销。

## 1. 背景

`033` 建成总账后，业务单据（采购 / 销售 / 收付款 / 成本）已能自动生成凭证，但**期间费用**（差旅 / 办公 / 招待…）仍是账外动作：

- 员工垫付 / 报销走线下，费用不落总账，利润表缺"期间费用"这一块，与"业务财务一体"的目标不符。
- `031` 已有费用类科目（损益类）、`034` 已有现金 / 银行账户、`033` 已有自动凭证写入通道——费用报销只差一张单据与一条凭证模板。

本规格补上**费用报销**：登记报销单（员工 + 费用明细科目 + 支付账户）→ 审批 → 自动生成费用凭证（借 费用科目 / 贷 现金或银行）。

## 2. 目标

1. **费用报销单**：员工 / 报销日期 / 支付账户 / 费用明细（费用科目 + 金额 + 摘要）/ 合计；三态（草稿 → 已审批 / 已作废）。
2. **自动凭证**：审批通过时同事务生成凭证（`SourceType = Expense`；借各费用科目 / 贷 现金或银行），期间结账 / 映射缺失整体回滚（复用 `033`）。
3. **作废**：草稿可作废（不动账）；**已审批不可作废**（如需冲销走反向报销单 — 见范围外）。
4. **权限与菜单**：权限点续行 `028` §0.2（`expenses.*`）；菜单「财务」分组续行（`025` §0.2）。
5. **前端**：报销单列表 / 表单 / 详情；**e2e 覆盖**。

## 3. 功能点

- **F1 列表**：`GET /api/expenses`（单号 / 员工关键词、状态、日期区间 + 分页）。
- **F2 登记 / 编辑**：`POST`、`PUT /{id}`（仅草稿，非草稿 → `40185`）；单号 `EX + yyyyMMdd + 4`；合计后端计算。
- **F3 审批**：`PUT /{id}/approve`（仅草稿，重复 → `40186`）；校验费用科目为**损益类末级启用**（否则 `40187`）；同事务生成凭证。
- **F4 作废**：`PUT /{id}/void`（仅草稿，非草稿 → `40185`）。
- **F5 权限与菜单**：`028` §0.2 续行 `expenses.*`；`025` §0.2「财务」分组续行。
- **F6 e2e**：建报销单 → 审批 → 凭证生成（总账可见）；费用科目非法 `40187`；重复审批 `40186`。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（科目校验、审批幂等、凭证模板、作废限制）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿；`npm run test:e2e` 全量通过（新增 `expense.spec.ts`）。
3. 手工验证：
   - 建报销单（差旅费 500 + 办公费 300，支付账户「现金」）→ 审批 → 凭证「借 差旅费 500 / 借 办公费 300 / 贷 库存现金 800」，科目余额表体现。
   - 费用明细选非损益类科目 → `40187`；重复审批 → `40186`；已审批编辑 / 作废 → `40185`。
   - 期间已结账时审批 → 整单回滚（`033` 既有 `40154`）。
4. 口径单一：状态流转、凭证模板、科目校验只在 `design.md` §0 定义一次；余额 / 报表口径引用 `033` §0.4。
5. 联动：`028` §0.2 续行、`025` §0.2「财务」分组续行、`033` §0.1 `VoucherSourceType` 续行、`ROADMAP` §6 错误码续行、§7 移出「范围外」。

## 5. 范围外（不做）

- **预算控制 / 费用标准 / 超标拦截**：见 `054-erp-budget`（待评估），本期不联动。
- **已审批的冲销 / 红字报销单**：本期已审批不可逆；如需红冲另评。
- **借款 / 备用金 / 冲销**：不做。
- **多级审批 / 接入 `042` 单据审批**：本期单级「审批」动作；接 `042` 需扩展其单据类型集合，另评。
- **发票查验 / 票据影像 / 附件上传**：不做文件存储。
- **差旅申请单 → 报销单的两段式**：一期一步式（直接报销）。
- **费用分摊到部门 / 项目 / 成本对象**：本期凭证不挂部门 / 项目辅助核算（`033` 无辅助核算维度）。
- **报销单导出 / 打印**：一期不做。
