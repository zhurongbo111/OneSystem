# 需求规格：列表导出 Excel 与单据打印（erp-export）

> 进销存扩展路线（`specs/ROADMAP.md`）批次三第三项；高频但独立的小功能，可随时插入（不阻塞其他规格）。
> 本规格含一处**全局契约例外**（文件下载接口不进统一响应），见 `design.md` §0.1。

## 1. 背景

现状数据只能「看着」不能「带走」：

- **无法导出**：业务列表（商品 / 往来 / 库存 / 单据 / 流水 …）都只有屏幕分页浏览；`006` 的 CSV 导出是**示例页**（`ListShowcaseView`，纯前端静态数据）的演示能力，业务页没有。
- **无法打印**：采购入库、销售出库、退货、盘点等单据在实际业务里需要纸质凭证（给仓管、司机、客户、供应商对账），现在只能截屏或手抄。
- **报表无法交付**：`025` / `026` 的报表页只能在线看，给财务 / 老板的往往要 Excel。

导出**必须在后端生成**：列表是服务端分页的，前端导只能导当前页；「导出当前筛选的全量数据」才是业务要的语义。打印**必须在前端做**：凭证版式与纸张设置属浏览器能力，后端产 PDF 会引入排版依赖（本规格不做 PDF）。

## 2. 目标

1. **列表导出 Excel**：`025` §0.2 菜单各业务域列表统一提供「导出 Excel」，导出**当前筛选条件下的全量数据**（不受分页限制），服务端生成 xlsx。
2. **单据打印**：单据类页面提供「打印」入口，进入**打印视图**（脱离侧边栏布局的独立路由），版式适配 A4 纵向与浏览器打印。
3. **报表导出**：`025` / `026` 的 5 个报表页复用同一导出能力，导出含**合计行**。
4. **统一呈现与反馈**：导出按钮位置与分组沿用 `006` §0（数据操作靠右）、打印入口在单据详情 / 列表操作列（`011` §0 图标与颜色约定）、loading 按 `010` §0（`exporting`）。
5. **契约例外可控**：文件下载接口的例外条款、错误回退（服务端错误仍返回统一响应 JSON）与前端处理方式在本规格 `design.md` §0.1 定义一次，成为后续所有下载类接口的唯一依据。

## 3. 功能点

- **F1 导出后端能力**：新增 `IExcelExporter`（Core 抽象）+ `ClosedXML` 实现（Infrastructure），按「表头 + 行 + 可选合计行」的通用表格模型生成 xlsx（列宽自适应、冻结表头、金额 / 数量格式、日期格式）。
- **F2 各域导出用例**：每个域的 Controller 追加 `GET /api/<资源>/export`（沿用各域列表的筛选参数，忽略分页参数），对应用例放各域 `Features/<域>/Export<X>`。
- **F3 导出内容**：列集 = 该域列表列定义（去掉序号列、操作列）+ 创建人 / 创建时间；单据类导出**两个工作表**（表头 + 明细）；报表类导出含**合计行**（`design.md` §0.2）。
- **F4 单据打印视图**：新增打印路由（顶层路由、不进 `AppLayout`）：采购入库 / 销售出库 / 采购退货 / 销售退货 / 收付款 / 库存盘点（`031` 调拨落地后追加）；内容 = 单据头 + 明细 + 合计 + 打印时间与操作人；页面提供「打印」按钮（调 `window.print()`）与「返回」。
- **F5 前端导出交互**：导出按钮 `exporting` loading → 触发浏览器下载（`Blob` + `<a download>`）；文件名 `<域>_<yyyyMMddHHmm>.xlsx`；失败按统一提示（`Message.error`）。
- **F6 e2e 覆盖**：导出（Playwright `download` 事件：文件名与非空断言）、打印视图渲染与关键字段断言。

## 4. 验收标准

1. `cd backend && dotnet build` / `dotnet test` 通过（含各导出用例的筛选传参、列集、合计行、错误回退的单测）。
2. `cd frontend && npm run type-check` / `npm run lint` / `npm run build` 全绿。
3. `cd frontend && npm run test:e2e` 全量通过（含新增 `export.spec.ts`；既有各域 spec 因操作行按钮增加需回归）。
4. 手工验证：
   - 商品列表：筛选某分类后导出 → xlsx 只含该分类商品，行数 == 列表 `total`（**不是**当前页行数）。
   - 采购入库列表导出 → 工作表 1 为单据行、工作表 2 为明细行，明细含所属单号。
   - 进销存报表导出 → 含与页面一致的合计行。
   - 采购入库详情打印 → 打印视图无侧边栏与工具条，含单号 / 供应商 / 日期 / 明细 / 合计；`Ctrl+P` 预览分页正常。
5. 契约例外：导出接口成功时返回 `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`（非统一响应 JSON）；筛选参数非法（如 `pageSize` 越界）与服务端异常时**仍返回统一响应 JSON**（前端按 `Content-Type` 区分并提示）。
6. 权限（`028` 交付后）：导出按钮与导出接口受 `<域>.export` 权限点约束；`028` 交付前为「登录即可」。

## 5. 范围外（不做）

- **PDF 导出 / 服务端排版打印**：打印走浏览器打印（用户可选「另存为 PDF」）；不引入 PDF 排版依赖。
- **导入（Excel 导入商品 / 库存 / 单据）**：仅导出；导入需模板校验与错误行反馈，另立规格。
- **自定义导出列 / 导出模板**：导出列集固定（`design.md` §0.2），不支持用户选列或自定义模板。
- **异步导出 / 大文件分片 / 导出历史**：同步生成（单组织数据量下秒级返回）；不做导出任务中心。
- **定时导出与邮件推送**：不做。
- **条码 / 标签打印**：属仓储作业（`specs/ROADMAP.md` §5 WMS 范围），不做。
- **打印版式定制（logo / 抬头 / 多联单）**：本期打印视图为固定简洁版式，不提供模板配置。
