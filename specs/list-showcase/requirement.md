# 需求规格：列表页样式参照（list-showcase）

## 1. 背景

后续业务开发会频繁出现"列表页"（搜索 + 筛选 + 表格 + 分页 + 批量操作等）。为避免每个功能重复摸索布局与交互，需要一个**纯前端的列表页参照模板**，沉淀本项目列表页的标准布局、交互与样式约定。

## 2. 目标

- 提供一个功能齐全、可直接抄改的列表页页面（示例业务：用户列表）。
- **不设计后端、不调用接口**：数据为前端写死的静态 Mock 数据。
- 覆盖列表页常用功能，作为后续业务的样式/布局/交互基准。

## 3. 范围

### 3.1 本期包含

| 功能 | 说明 |
|---|---|
| 页面标题 | 标题行仅显示"用户列表"；操作按钮统一收纳到表格上方的工具条（见验收标准 12） |
| 关键词搜索 | 按名称/邮箱模糊匹配 |
| 条件筛选 | 状态下拉筛选（全部/启用/禁用） |
| 角色筛选 | 角色下拉筛选（全部/管理员/编辑/访客） |
| 搜索/重置 | 搜索应用条件、重置还原默认 |
| 布局 | 工具条 = 筛选区（多列响应式栅格，窄屏自动换行成多行）+ 操作区（新增/导出/列设置/刷新/批量删除），紧贴表格上方 |
| 表格 | 序号、名称、邮箱、角色（Tag）、状态（Tag 开/关）、创建时间（格式化）、操作列（编辑/删除，删除走 Popconfirm 并移除） |
| 批量操作 | 多选（含表头全选）+ 批量删除（二次确认） |
| 排序 | 名称 / 创建时间列可点击排序（升/降/取消） |
| 列显示设置 | 可勾选显示/隐藏部分列 |
| 导出 | 导出当前筛选结果为 CSV 文件下载 |
| 刷新 | 恢复初始数据（演示删除后的还原） |
| 分页 | 前端分页，默认 10 条/页，可切换 10/20/50，显示总数与"条/页" |
| 空状态 | 筛选无结果时显示空状态 |

### 3.2 本期不包含

- 任何后端接口、真实数据、登录态数据。
- 新增/编辑的表单弹窗（主按钮仅提示，不实现表单）。
- 权限控制、行内编辑、拖拽等高级能力。

## 4. 验收标准

1. 已登录用户登录后从侧边菜单"列表示例"进入 `/list` 页面，页面按上述布局渲染，数据为静态 Mock（约 25 条）。
2. 关键词搜索、状态筛选、角色筛选可叠加生效；"重置"还原为全量、默认分页。
3. 批量勾选后"批量删除"二次确认，确认后移除对应行并清空勾选。
4. 名称/创建时间列可排序，排序后分页基于排序结果。
5. 列显示设置可隐藏/恢复列，隐藏后表头与单元格同步。
6. "导出"下载当前筛选结果的 CSV 文件。
7. "刷新"恢复初始数据。
8. 分页可翻页、切换每页条数，跨页后表头全选作用于当前页。
9. 筛选无结果显示空状态。
10. 全部样式基于 Arco 组件与主题变量，无自造样式体系。
11. `npm run build`、`npm run lint` 通过；`npm run test:e2e` 中 `list-showcase.spec.ts` 全绿。
12. 操作按钮与筛选区同处表格上方工具条，距表格最近；筛选项按栅格多列排布，窄屏下换行为多行，不挤压、不溢出；筛选行与操作行之间以分隔线区分，操作行与表格间距紧凑（约 8px），操作行按钮为小号（size=small）。

## 5. 非目标 / 备注

- 数据、行为均为前端静态模拟，目的是布局与交互参照，非真实业务。
- 页面纳入 `AppLayout` 布局（`/list` 为其子路由），需登录访问。
